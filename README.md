# Ember Finance - Personal Financial Management

Warm Earth UI · Personal tracker · Expo + React Native (APK-ready)

## Screens (v1 - production)
1. **Home** - live balance hero, last-7-days spend bars (real weekday labels), month income/spent from records, budgets preview, recent activity, goals preview. Avatar / person icon → Profile, bell → Notifications (dot only when alerts exist). All "See all" links navigate.
2. **Transactions** - live records, search + filter pills, long-press to delete with confirm.
3. **Add (FAB modal)** - Expense/Income toggle, big amount input, quick amounts, manual-typing category field (no preset list), note, working day stepper. Saving writes to records instantly.
4. **Budgets** - limits with spend computed live from this month's records; over/near-limit states update as you add transactions.
5. **Goals** - create goals (name + target, validated), Add funds chips (+50/+100/+250) per goal, live % and "to go".
6. **Insight** - compact single-viewport layout (no scroll needed): Spent/Saved chips, savings-rate card, top categories with share %, report card with "Plan November" → Budgets.
7. **Profile** - edit full name, email, currency (USD, EUR, GBP, PHP, JPY, **IDR**). Amounts app-wide render in the selected currency; IDR displays as **Rp.** (code stays `IDR` in data).
8. **Notifications** - computed alerts (over-budget, near-limit ≥85%, goal halfway/complete) with an All-clear empty state.

No demo modes, preview banners, or dead buttons remain.

## Design system
- Base: `#FAF7F2` bg, `#FFFFFF` surface, `#E8E2DC` border, `#1C1917` ink, `#78716C` muted
- Accent: terracotta `#C86E4B`, dark `#A9552F`, soft `#FBE9DD`
- Success sage `#5B8C5A`, danger `#C14A3A`
- Radius 16/22/28, 4px spacing scale, flat cards (border, no shadows)
- Display font: Fraunces / system heavy; Body: Inter / system
- Touch targets ≥44px, WCAG AA contrast, prefers-reduced-motion respected

## Run as an app (Expo Go - fastest, no build needed)
```bash
npm install
npx expo start
```
- On your Android phone, install **Expo Go**, scan the QR code → the app runs on your phone.
- Or press `a` for an Android emulator.
- Profile edits work immediately: Home → tap avatar / person icon → edit → Save.

## Build a real APK to install
```bash
npm i -g eas-cli
eas login
eas build -p android --profile preview
# APK download link appears in terminal + expo.dev dashboard
# Install the APK on any Android phone - no Expo Go needed.
```

Add `eas.json` if needed:
```json
{
  "build": {
    "preview": { "distribution": "internal", "android": { "buildType": "apk" } }
  }
}
```

## Structure
```
App.tsx - bottom tabs (dark floating bar + center FAB) + stack (Add modal, Insight, Profile, Alerts); providers: User, Tx, Goals
assets/ - icon.png, adaptive-icon.png, splash.png (generated by gen_icons.py), ANDROID_BUILD.md (Android Studio steps)
src/theme.ts - tokens
src/data/mock.ts - seed records, budgets, goals, currency map (IDR → "Rp." display), money/date/stats helpers
src/data/alerts.ts - computed notifications engine
src/store/ - UserContext (profile), TxContext (records + add/delete), GoalsContext (goals + fund)
src/components/ - Card, ProgressBar, SectionTitle (tappable actions), TransactionRow (live dates, long-press), AppIcon, ScreenHeader
src/screens/ - Home, Transactions, Add, Budgets, Goals, Insight (single viewport), Profile, Alerts
preview.html - static browser mockup, 8 phones (open for instant review)
```
